# Project overview 

This app uses Nestjs on the backend with Prisma. We will be building an app called Eventer to schedule and track events.

On the frontend we will be using Solidjs.

We will have an admin interface and a user interface.

## Admin interface

The admin interface will be used to create and manage events.

## User interface

The user interface will be used to view events and register for them.

## Features

### Admin interface

- Create events
- Edit events
- Delete events
- View events
- View event registrations
- Export event registrations

### User interface

- View events
- Register for events
- View event details
- View event registrations
- Cancel event registration
